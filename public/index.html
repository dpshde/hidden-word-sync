Lost your sync key?

Nobody can recover it. Your library is encrypted with the key, and Hidden Word never keeps a copy.

Look in your password manager under this site's address. If you added a passkey, try Unlock with passkey. On a device that's still unlocked, open Sync from the ••• menu and choose Show sync key.

If none of that works, create a new library. If you saved a file from Backup, its Import brings your highlights back.
